Day 14 - Database Tasks

Practice MongoDB integration, Mongoose models, and database-backed API routes.

Task 1

Understand Database Types

Write a short summary for each of these:

  • Relational database (SQL): how tables, rows, and fixed schemas work.
  • Non-relational database (NoSQL): how documents and flexible schemas work.
  • Why MongoDB is a good fit for Node.js apps.
Task 2

Connect Express to MongoDB

Update your server to use Mongoose and connect to a database.

const mongoose = require("mongoose"); mongoose.connect(process.env.MONGODB_URI || "mongodb://127.0.0.1:27017/userdb") .then(() => console.log("MongoDB connected")) .catch(err => console.error(err));
  • Install Mongoose with npm install mongoose.
  • Use local MongoDB or MongoDB Atlas.
  • Ensure the server fails fast if the connection cannot be established.
Task 3

Create a User Schema

Create a Mongoose model in models/User.js with these fields:

  • name: String, required
  • email: String, required
  • age: Number
  • isActive: Boolean, default true
const userSchema = new mongoose.Schema({ name: String, email: String, age: Number, isActive: Boolean }); module.exports = mongoose.model("User", userSchema);
Task 4

Replace In-Memory Users with MongoDB

Update these routes to use the database instead of an array:

  • GET /users
  • POST /users
  • PUT /users/:id
  • DELETE /users/:id

Use Mongoose methods like find(), findById(), save(), and findByIdAndDelete().

Task 5

Add New Database Routes

Implement these extra routes:

  • GET /users/active → only active users
  • GET /users/age/:min → users older than the given age
  • GET /users/search/by-name?name=<name> → case-insensitive search

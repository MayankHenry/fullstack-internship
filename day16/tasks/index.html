Day 16 - Authentication Tasks

Build a secure auth API using MongoDB, bcrypt hashing, and JWT.

Task 1: Signup

Create a new user using POST /signup.

  • Send name, email, and password.
  • Confirm the password is hashed in the database.

Task 2: Login

Login with POST /login and get a JWT.

  • Use the correct password to receive a token.
  • Use a wrong password to test invalid credentials.

Task 3: Protected Profile

Access GET /profile with your token.

  • Add Authorization: Bearer <token> header.
  • Verify the route is rejected without a token.

Task 4: Add Authorization

Extend your model and routes for roles.

  • Store a role field with default user.
  • Protect /admin so only admins can access it.

Task 5: Secure Error Handling

  • Show clear validation errors on signup.
  • Return proper error codes for invalid token or auth failure.

Tip: Use Postman or curl for signup/login, then send the JWT in the Authorization header.

Day 17 — Connecting Frontend with Backend (Fetch API & Axios)

This folder contains lesson materials and a small demo: a simple Express backend (in-memory) with JWT authentication and a frontend dashboard that uses Axios and Fetch to perform CRUD operations.

Run the backend (from day17/backend):

1. npm install
2. npm start

Open the frontend at: day17/Hands-on-mini-project/index.html (load in your browser) and use the login form to authenticate. The demo backend runs on http://localhost:3000 by default.

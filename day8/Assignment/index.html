Fetch posts from the JSONPlaceholder API and print the first 5 titles.

📝 Assignment 2

Simulate Download with Random Time

Requirements:
  • Function: simulateDownload(file)
  • Random delay: 1-5 seconds
  • Download 3 files sequentially
  • Use async/await

📝 Assignment 4

Get Weather with Simulated API

Write an async function getWeather(city) that simulates fetching weather info with setTimeout.

Requirements:
  • Async function: getWeather(city)
  • Return mock weather data (temp, condition, humidity)
  • Use setTimeout to simulate API delay (1-3s)
  • Include error handling

🚀 Day 8 - Async JavaScript Practice Tasks

📋 Task 1: Sequential Logging

Print "One", then after 1 second "Two", then after 2 seconds "Three".

// Expected Output:
// One
// Two (after 1s)
// Three (after 2s)

📋 Task 2: Callback Function

Create a function doHomework(subject, callback) that prints "Homework done for X" and then calls the callback.

// Example: doHomework("Math", () => console.log("Time to play!"))
// Output:
// Homework done for Math
// Time to play!

📋 Task 3: Promise Resolution

Create a Promise that resolves after 3 seconds with "Download Complete".

// Expected Output (after 3s):
// Download Complete

📋 Task 4: Async Function

Write an async function fetchUser() that waits 2 seconds, then logs "User data received".

// Expected Output (after 2s):
// Fetching...
// User data received

# Day 10 Mini Project: Responsive Portfolio Website

This mini project is a responsive portfolio website built with HTML, CSS, and JavaScript.

## Features

- Navigation bar with smooth scrolling to page sections.
- Sticky header for easy navigation on scroll.
- Responsive sections for home, about, projects, gallery, and contact.
- Dynamic project list generated with JavaScript.
- Contact form validation for name, email, phone, and message.
- Dark mode toggle with local storage persistence.
- Image gallery with hover effects.

## Files

- `index.html` — main page structure.
- `style.css` — responsive styling and dark mode.
- `script.js` — project rendering, form validation, smooth scroll, theme toggle.

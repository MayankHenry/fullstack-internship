Task 1: Create Route for Single User by ID

Status: Practice Task from Lesson

Objective: Implement a route that returns a single user by their ID.

Requirements:

  • Route: GET /users/:id
  • Return user object if found
  • Return 404 error if user not found
  • Use find() method to locate user
// Expected implementation app.get("/users/:id", (req, res) => { const user = users.find(u => u.id == req.params.id); if (!user) return res.status(404).json({msg: "User not found"}); res.json(user); });
💡 Hint: Use parseInt() to convert the route parameter to a number before comparison.
Easy

Task 2: Search Users by Name

Status: Assignment #1

Objective: Create a search endpoint that filters users by name.

Requirements:

  • Route: GET /users/search?name=Rahul
  • Use query parameters (req.query.name)
  • Filter users by name (case-insensitive)
  • Return array of matching users
  • Handle no matches gracefully
// Expected implementation app.get("/users/search", (req, res) => { const name = req.query.name; if (!name) { return res.status(400).json({msg: "Please provide a name"}); } const results = users.filter(u => u.name.toLowerCase().includes(name.toLowerCase()) ); res.json(results); });
💡 Hint: Use toLowerCase() for case-insensitive matching. Test with: GET /users/search?name=rahul

Task 3: Add Age Field and Filter Adults

Status: Assignment #2

Objective: Extend the user model with age and create filtering logic.

Requirements:

  • Add 'age' field to user objects
  • Validate age (0-150 range)
  • Create GET /users/adults endpoint
  • Return only users with age ≥ 18
  • Handle users without age field
// Add age to sample data let users = [ {id: 1, name: "Rahul", email: "rahul@example.com", age: 22}, {id: 2, name: "Aditi", email: "aditi@example.com", age: 16} ]; // Adults filter route app.get("/users/adults", (req, res) => { const adults = users.filter(u => u.age && u.age >= 18); res.json(adults); });
💡 Hint: In POST/PUT routes, validate age: if (age < 0 || age > 150) { error }

Task 4: Extract and Return Only Emails

Status: Assignment #3

Objective: Create an endpoint that returns specific user fields.

Requirements:

  • Route: GET /users/emails
  • Return only id, name, and email fields
  • Use map() to transform data
  • Include total count in response
// Expected implementation app.get("/users/emails", (req, res) => { const emails = users.map(u => ({ id: u.id, name: u.name, email: u.email })); res.json({ count: emails.length, data: emails }); });
💡 Hint: Use array.map() to extract specific fields. This is useful for privacy (hiding sensitive data).
Hard

Task 5: Advanced Filtering with Multiple Parameters

Status: Challenge Task

Objective: Create a flexible filtering endpoint with multiple query parameters.

Requirements:

  • Route: GET /users/filter
  • Support query params: name, minAge, maxAge
  • All parameters are optional
  • Combine filters using AND logic
  • Return filtered results with count
// Expected implementation app.get("/users/filter", (req, res) => { let filtered = users; if (req.query.name) { filtered = filtered.filter(u => u.name.toLowerCase().includes(req.query.name.toLowerCase()) ); } if (req.query.minAge) { filtered = filtered.filter(u => u.age >= parseInt(req.query.minAge)); } if (req.query.maxAge) { filtered = filtered.filter(u => u.age <= parseInt(req.query.maxAge)); } res.json({count: filtered.length, data: filtered}); });
💡 Hint: Test with: GET /users/filter?name=Rahul&minAge=20&maxAge=30
Hard

Task 6: Implement User Validation Middleware

Status: Challenge Task

Objective: Create a reusable validation middleware for POST/PUT requests.

Requirements:

  • Create a middleware function
  • Validate name (required, non-empty)
  • Validate email (required, basic format check)
  • Validate age (optional, 0-150 range)
  • Apply middleware to POST and PUT routes
// Middleware function const validateUser = (req, res, next) => { if (!req.body.name || req.body.name.trim() === "") { return res.status(400).json({msg: "Name is required"}); } if (!req.body.email || !req.body.email.includes("@")) { return res.status(400).json({msg: "Valid email is required"}); } if (req.body.age && (req.body.age < 0 || req.body.age > 150)) { return res.status(400).json({msg: "Age must be 0-150"}); } next(); }; // Use middleware app.post("/users", validateUser, (req, res) => { // ... create user logic });
💡 Hint: Call next() to pass control to the next middleware/handler.

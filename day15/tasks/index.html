Day 15 - MongoDB CRUD Tasks

Build and test a user API backed by MongoDB using Mongoose.

Task 1: Create users

Use `POST /users` to add three users with unique emails.

  • Example body: { "name": "Rahul", "email": "rahul@example.com", "age": 22 }
  • Confirm each user is saved by calling `GET /users`.

Task 2: Read users

  • Fetch all users younger than 25.
  • Fetch one user by email using `GET /users` and a filter in your client.

Task 3: Update users

  • Update a user’s email address with `PUT /users/:id`.
  • Increase the age of all users by +1 (test with multiple `PUT` requests).

Task 4: Delete users

  • Delete one user by ID.
  • Delete all users older than 60 by calling `GET /users`, then deleting each match.

Task 5: Query filters

  • Find users aged between 20 and 30.
  • Find users whose name is either Aman or Neha.

Task 6: Validation

  • Try creating a user without a name — the API should return an error.
  • Try creating a user with an invalid email — the API should return a validation error.

Extra Practice

  • Build `GET /users/average-age` to return the average age of all users.
  • Try adding a `role` field to the schema later and fetch all admins.

Tip: Start MongoDB locally before running the project, or set `MONGODB_URI` for Atlas.

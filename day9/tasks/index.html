Day 9 – Tasks

Practice Tasks

  1. Install Git and set your name/email with git config --global user.name and git config --global user.email.
  2. Create day9-project, add an index.html, run git init, git add ., and git commit -m "Initial commit".
  3. Create a GitHub repo called my-first-repo, connect your local repo, and push to GitHub.
  4. Clone the repo to another folder, make a change, commit, and push.
  5. Create a branch named dev, commit a change there, then merge it into main.
  6. Push a branch to GitHub and open a pull request from that branch into main.

Git Commands to Practice

  • git init – start a repository
  • git status – see changed files
  • git add . – stage files
  • git commit -m "message" – save a snapshot
  • git branch – list branches
  • git checkout dev – switch branch
  • git merge dev – merge changes
  • git push -u origin main – send changes to GitHub
  • git pull origin main – get latest remote changes

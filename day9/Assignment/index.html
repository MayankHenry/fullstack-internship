Day 9 – Introduction to Git & GitHub

1. What is Version Control?

Version control helps you track every change in your code. Without it, managing multiple versions and collaborating with others becomes messy.

  • Git tracks history of file changes.
  • It allows you to rollback bad changes.
  • Multiple developers can work together safely.
  • GitHub provides remote backup and sharing.

2. Installing Git & Setup

Install Git on your machine and set your identity so commits include your name and email.

git config --global user.name "Your Name"
git config --global user.email "your@email.com"
Practice Task 1: Install Git and configure your name and email.

3. Creating Your First Repository (Local Git)

Initialize a Git repository inside your project folder, add files, then commit.

cd project-folder
git init
git status
git add .
git commit -m "Initial commit"
Practice Task 2: Create a folder named day9-project, add an index.html, initialize Git, add files, and commit.

4. GitHub Basics

GitHub is an online platform for Git repositories. It helps you share projects and build a developer portfolio.

To connect your local repo to GitHub:

git remote add origin https://github.com/username/repo.git
git branch -M main
git push -u origin main
Practice Task 3: Create a GitHub repo named my-first-repo and push your day9-project code to it.

5. Common Git Commands

  • Clone: git clone https://github.com/username/repo.git
  • Pull: git pull origin main
  • View history: git log
  • Undo changes: git checkout -- filename
Practice Task 4: Clone your repo to another folder, edit a file, commit, and push the change.

6. Branching in Git

Branches let you work on features without changing the main project.

git branch dev
git checkout dev
// make changes
git commit -m "Add feature"
git checkout main
git merge dev
Practice Task 5: Create a branch named dev, make a change, commit it, and merge it into main.

7. GitHub Collaboration (Pull Requests)

A pull request is how you propose changes on GitHub from one branch into another.

Workflow:

  1. Fork or branch the repo.
  2. Make changes locally.
  3. Push the branch to GitHub.
  4. Open a pull request.
Practice Task 6: Create a new branch on GitHub, push your changes, and open a PR to merge into main.

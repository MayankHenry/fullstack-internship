# Day 12 - Express.js Server with Static Files

A simple Express.js server that serves static HTML files.

## Installation

```bash
npm install
```

## Running the Server

```bash
npm start
```

The server will run on `http://localhost:3000`

## Features

- Static file serving from `public/` directory
- Basic routing
- HTML file serving

## Files

- `server.js` - Main server file
- `public/index.html` - Home page
- `public/contact.html` - Contact page
